# Fonts

Headings use **PP Neue Montreal** (Pangram Pangram), the same font as the Framer design.
It is a commercial font, so the files are not committed.

With a license, drop these files here and the site picks them up automatically:

- `PPNeueMontreal-Book.woff2` (weight 400)
- `PPNeueMontreal-Medium.woff2` (weight 500)

Without them, headings fall back to Inter Tight.
